# WHAT IS FLASHWIZ APP?  
FlashWizApp is an android application that helps you learn English effectively using flashcards. With FlashWizApp, you can create your own flashcards or choose from a variety of pre-made decks. You can also track your progress and set reminders to help you stay on track.  

 # FEATURES  
- Create and customize flashcards  
- Access pre-made decks for various topics  
- Monitor your learning progress  
- Receive timely reminders to keep you motivated  
- Optimize learning with spaced repetition  
- Connect with friends and form study groups  
- Learn English effectively and efficiently
